# Workshop 3 — เกมความจำ 4 สี (Plan first)

## Prompt 1: ขอแผน
คุณคือผู้สอน Flutter สำหรับมือใหม่ ขอวางแผนเกมความจำ 4 สี
ปุ่มแดง เขียว เหลือง น้ำเงิน ขนาดใหญ่ 2x2 มี Start และตัวนับเริ่ม 0
กด Start สุ่มสีต่อท้ายลำดับเดิม จากนั้นไฟสว่างทีละสี
ผู้เล่นกดถูกครบจะเพิ่มรอบ 1 พร้อมสุ่มสีเพิ่ม 1
กดผิดแจ้งเตือนและกลับ 0
ขอแผนตัวแปรสถานะ ลำดับช่วง เวลาไฟสว่างและดับ กรณีพิเศษ และคำถาม
ยังไม่เขียนโค้ด

## ตรวจแผนและปรับ
แก้อย่างน้อย 1 จุด:
- ระหว่างแสดงไฟ Start และปุ่มสีต้องกดไม่ได้
- กดผิดให้ขึ้น "ผิด! ได้ X รอบ" 1.5 วินาทีและรีเซ็ต
ตอบ: ไม่มีเสียง; ไฟสว่าง 0.6 วินาทีและดับ 0.25 วินาที

## Prompt 2
ยืนยันแผน ขอ lib/main.dart แบบเต็มไฟล์
ใช้ StatefulWidget, AnimatedContainer เรืองแสง
Random จาก dart:math, async/await, Future.delayed
ตรวจ mounted หลังทุกการรอเวลา และกันแสดงลำดับซ้อนกัน

บริบท: Flutter stable, Dart null safety, Material 3,
GitHub Codespaces Web Server, สร้าง APK Android ได้
ไม่ใช้ package ภายนอก ส่งโค้ดเต็มไฟล์

## ทดสอบ 5 กรณี
1. Start → ไฟแรกสว่างหนึ่งครั้ง, รอบยัง 0
2. กดถูกครบ → รอบเป็น 1 และลำดับเพิ่มต่อจากเดิม
3. กดระหว่างไฟแสดง → ไม่มีผล
4. กดผิด → แจ้งเตือนแล้วรีเซ็ต 0
5. Start ระหว่างรอกด → เริ่มใหม่ไม่มีไฟซ้อน
