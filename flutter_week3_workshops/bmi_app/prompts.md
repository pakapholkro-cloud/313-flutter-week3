# Workshop 1 — BMI (One-shot)

Prompt: คุณคือผู้สอน Flutter สำหรับมือใหม่ สร้างแอป BMI ในไฟล์ lib/main.dart
มี AppBar, ช่องน้ำหนัก (กก.) ส่วนสูง (ซม.), ปุ่มคำนวณและล้างค่า
BMI = น้ำหนัก / (ส่วนสูงเป็นเมตร)^2 แสดงทศนิยม 2 ตำแหน่ง
น้อยกว่า 18.5 ผอมสีฟ้า, 18.5 ถึงน้อยกว่า 23 ปกติสีเขียว,
23 ถึงน้อยกว่า 25 ท้วมสีเหลือง, 25 ถึงน้อยกว่า 30 อ้วนสีส้ม,
ตั้งแต่ 30 อ้วนมากสีแดง พร้อมคำแนะนำภาษาไทย
กรอกว่าง ไม่ใช่ตัวเลข หรือค่าที่น้อยกว่าหรือเท่ากับ 0 แสดง SnackBar

บริบท: Flutter stable, Dart null safety, Material 3,
GitHub Codespaces Web Server, สร้าง Android ได้, ไม่ใช้ package ภายนอก,
ส่งโค้ดเต็มทั้งไฟล์

## ตารางทดสอบ
45/165 = 16.53 ผอม; 60/170 = 20.76 ปกติ;
70/170 = 24.22 ท้วม; 85/170 = 29.41 อ้วน;
95/170 = 32.87 อ้วนมาก; ช่องว่างต้องแจ้งเตือน
